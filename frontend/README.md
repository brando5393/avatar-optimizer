# frontend

SvelteKit app, static adapter — builds to plain HTML/CSS/JS for S3 +
CloudFront. No server runtime.

## Commands

```bash
npm run dev       # local dev server
npm test          # Vitest component tests
npm run test:e2e  # Playwright, including an axe-core a11y sweep
npm run lint       # svelte-check
npm run build
```
